# nac-portfolio

The source of Nicholas Carsner's portfolio: a catalogue of already-built things —
web applications, command-line tools, published packages and writing.

The site is not built yet. What is here is the prototype that settled its design.

## prototype_portfolio/

A throwaway Streamlit prototype, written to answer design questions and then to
be deleted. It compared three whole-site structures, three visual treatments and
three ways of presenting the viewer's appearance controls, each in a real
browser. Its own [README](./prototype_portfolio/README.md) records what was
settled, and cites the commits where the rejected alternatives can still be read.

It is prototype code by its own admission: no tests, no error handling, and all
content is invented placeholder data. Run it with `./prototype_portfolio/run`.
Do not promote it as-is.
