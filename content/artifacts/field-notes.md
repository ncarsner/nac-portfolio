## Notes

A separate property, deliberately. The blog has its own address, its own theme
and its own history, and folding it into this site would mean rewriting a
working thing to gain what a link already provides. The three most recent posts
appear in the catalogue here; the rest live where they were published.

It is built with Pelican and deployed to GitHub Pages by a GitHub Actions
workflow — the same shape as the site you are reading, which is not a
coincidence. Getting a static Python toolchain working there is what made it the
obvious choice here.
